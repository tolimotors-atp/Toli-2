# TOLI Motors visual system audit

## Baseline

The production build renders a React homepage, the direct Service Request route, three policy pages and a custom 404. The homepage includes the approved workshop Hero, four service tiles, the main menu and chapter rail, Services, Vehicle Components, Process, Trust, Gallery, Booking, Contact/WhatsApp and the footer. Service Request also opens as a dialog. TOLI AI is a separate dialog. The vehicle views are static MU-X images with optional illustrations or controls. No homepage canvas, GLB or Three.js bundle was observed. Development tools and unused 3D source remain outside this change.

## Theme and component baseline

Dark mode uses a strong red gradient in almost every below-Hero section, the enquiry surface, the AI panel and the footer. The red SUV, selection controls and calls to action compete with those backgrounds. Light mode uses cleaner pearl surfaces but still applies layered gradients, badges, chrome and panel shadows to many elements. Services need a clear list and detail surface, Vehicle Components and Process need image prominence and legible controls, and Trust can use dividers instead of a border and shadow on every item. Gallery frames should support the photos. Booking, the enquiry dialog, contact and footer need one quiet set of actions and input states.

The remaining light Hero brightening comes from the first radial gradient in the desktop atmosphere pseudo-element and the mobile/tablet `--hero-daylight-copy` layer. The photo already carries its own ceiling fixtures and window light. Further reduction must be checked against beam contrast. The existing phone pill already meets the grid, icon and link requirements. Its materials and geometry are the baseline to preserve. No dark Hero lighting change is needed.
